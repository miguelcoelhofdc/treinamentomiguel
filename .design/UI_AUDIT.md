# Initial UI audit

The previous entry point switches between coaching and a legacy journey. Home prioritizes plan creation and prescribed training, while charts and historical measurements are scattered behind Evolution tabs and collapsible panels. Five primary navigation items compete with duplicated activity forms. Detailed strength records are associated by date and exercise name, so two same-day sessions cannot be distinguished.

The replacement must prioritize actual records, preserve each profile's local data, use four navigation destinations and one chart, and associate new strength sets with a session. Check-ins must accept partial data without default ratings. Mobile forms need 44px targets, keyboard-safe sheets, wrapping labels and no horizontal overflow. Data errors must offer retry and save failures must retain the draft.

The sales goals and whiteboard are separate modules and retain their routes and styles. No publication, messaging, permission changes or customer-data export is part of this work.
