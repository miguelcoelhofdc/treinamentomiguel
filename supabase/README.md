# Histórico do Meu Ritmo

O Meu Ritmo abre os perfis diretamente e salva os registros no navegador de cada aparelho. Em **Ajustes → Dados e backup**, é possível exportar e importar um arquivo JSON para transferir registros.

O arquivo `training_sync.sql` documenta a estrutura usada pela sincronização anterior. Os registros enviados ao Supabase continuam no projeto original. A versão local abre os registros já salvos no aparelho.
